Enhanced Input:WASD 修改器原理(第 3 章实操结论)

键盘按键是开关量(按下=+1),进入二维值(Axis2D)时默认落在 X 轴。我们的约定:Y=前后,X=左右。因此:

按键修改器变换过程结果
D(右)无(+1,0) 原样+X
A(左)取反(+1,0) × −1−X
W(前)拌和输入轴值(YXZ)X 的值换到 Y+Y
S(后)拌和 + 取反先换到 Y 再 × −1−Y

记忆:原始值天生"向右";A 取反,W/S 先拌和换轴,S 再取反。
