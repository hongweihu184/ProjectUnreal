这份清单是什么

工程里所有"非引擎默认"的东西——我们自己写的代码、改的配置、造的资产、调的参数——全部登记在册。用途:① 迁移机器/重装时核对"我们的东西都在不在";② 新接手的 AI/人快速分清"哪些是引擎自带、哪些是我们加的";③ 每次新增自定义内容就追加一行。
