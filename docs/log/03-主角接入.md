# 行动日志 03 · 主角接入

> 状态:✅ 完成(2026-10-07)
> 产出:Greystone 可 WASD 走跑跳、Idle↔Jog 动画、-15° 俯视相机;输入资产 IA×3 + IMC;BS_Jog + ABP_Greystone

## 目标

第三人称主角:输入、移动、动画、相机完整,替代默认角色。

## 行动步骤

### 1. C++(AI):移动/相机/输入绑定

BaseCharacter 增加:弹簧臂+相机组件(构造函数)、`SetupPlayerInputComponent`(AddMappingContext + BindAction)、`Move()/Look()`、`DefaultCameraPitch=-15`(BeginPlay 写 ControlRotation,EditAnywhere 蓝图可调)、自由移动模式(bOrientRotationToMovement=true)。

### 2. 输入资产(脚本 + 手补)

- `Tools/setup_input.py` 无头生成 IA_Move/IA_Look/IA_Jump + IMC_Default(Python API:Key 用 `import_text` 构造;`imc.map_key` 可映射)
- **修改器脚本写不进**(map_key 返回副本),编辑器手动补:**D 无 / A 取反 / W 拌和(YXZ)/ S 拌和+取反**(bool 默认落 X 轴原理,见术语表)

### 3. 动画(用户)

- **BS_Jog**:普通混合空间(非 1D,官方推荐),横轴 Speed 0~400,Idle@0 / Jog_Fwd@400
- **ABP_Greystone**:事件图表(Speed = Pawn Owner.Velocity 的 XY 长度;IsInAir = Movement Component.Is Falling);状态机 Ground(BS_Jog)/ Air(Jump_Fall),转换条件 IsInAir / NOT IsInAir
- BP_BaseCharacter 的 Mesh 动画类 = ABP_Greystone

### 4. 相机调参(用户)

CameraBoom 面板:臂长/相机延迟/碰撞;**默认俯角用控制器方案**(弹簧臂相对旋转被 pawn 控制旋转整体替换,无效!见 P17);Y 轴反转与否在 IMC 加"只翻 Y"的 Negate。

### 5. 测试图搬家

Maps/NewMap(GUI 拖拽,WP 地图脚本搬家必失败,P15);Config/DefaultEngine.ini 默认图路径同步。

## 踩坑

P15(WP 地图脚本搬家)、P16(IMC 修改器写不进)、P17(弹簧臂相对旋转无效)、GAS 头文件在 `Abilities/` 子目录(GameplayAbility.h 路径)。

## 验收

WASD 四向走跑、空格跳跃、Idle↔Jog 平滑、-15° 俯视构图、滑步可接受。
