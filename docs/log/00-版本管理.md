# 行动日志 00 · 版本管理(嵌套双仓库)

> 状态:✅ 完成(2026-10-05)
> 产出:外层仓库(代码/文档,推 GitHub)+ 内层仓库(Content 素材,仅本地)

## 目标

工程纳入 Git 可回滚;轻量文件上 GitHub(简历可附),19GB 素材本地自管。

## 行动步骤

1. `git config --global core.longpaths true`(Windows 必开,UE 路径深)
2. `.gitattributes`:`*.uasset` `*.umap` 标记 binary,防换行符污染
3. 外层:工程根 `git init -b main` → 基线提交(uproject + Config + docs),.gitignore 排除 Content/ 与引擎缓存
4. 内层:`cd Content && git init -b main` → 素材基线提交(19GB)
5. GitHub 建**空白**公开仓库(不勾 README/.gitignore)→ `git remote add origin ...` → `git push -u origin main`

## 日常口诀

改代码/文档 → 根目录 commit;动素材 → Content 目录 commit;两者都动各 commit 一次。推送只推外层。

## 踩坑

- **P12**:首次 push `Connection was reset` —— git 不走系统代理。解法:`git config --global http.proxy http://127.0.0.1:7897`(https 同理;代理关闭后需 unset)。详见错题本。
