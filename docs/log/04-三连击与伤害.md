## 设计总览(GAS 连击范式)

```
IA_Attack(左键)
  → TryActivateAbilitiesByTag("Ability.Attack.Light")
  → 三个 GA 都被尝试:
      GA_1(标签 .Light.1,无门槛)→ 直接激活,播 PrimaryA
      GA_2/3(标签 .Light.2/.3,激活需 State.Combo.Window)→ 窗口外激活失败
  → GA 内:PlayMontage
      命中通知(Event.Montage.Attack.Hit)→ WaitGameplayEvent → SphereTrace → GE_Damage
      窗口通知(Event.Combo.WindowOpen)→ Apply GE_ComboWindow(0.5s,授予 State.Combo.Window)
  → 窗口期内再按左键 → GA_2 满足条件激活 → Cancel GA_1 → 播 PrimaryB → 同理接 C
```

关键点:命中帧与窗口开启点都是**蒙太奇时间轴上可拖的通知**(数据,不是代码);`Ability.Attack.Light.1/2/3` 利用标签父子匹配(`Ability.Attack.Light` 可匹配全部三段)。

### 2. 自定义通知类 AN_SendGameplayEvent(✅ 已完成)

蓝图继承 AnimNotify;公有变量 EventTag(GameplayTag);重写"接收通知":Mesh Comp → Get Owner → **Send Gameplay Event to Actor**(EventTag)→ 返回 true。
用途:一个类打天下——命中帧、窗口开启都靠它,蒙太奇里每个实例填不同 EventTag。
原理:通知不找具体接收方,GA 也不认特定动画,**双方只认标签,彻底解耦**。
