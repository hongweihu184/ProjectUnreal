# 战斗系统策划案 · 魂类 ARPG Demo

> 版本 v0.1(2026-10-08)｜作者:策划 + AI 结对
> 本文档是**设计决策的契约**:每个规则写清"是什么、为什么、我们选择了哪条路"。
> 非通用常识,而是**本项目自己的要求**——别家游戏的做法只是参考。

## 0. 设计支柱(不可动摇)

1. **魂系手感**:每一次输入都有承诺(前摇必出、后摇真实、体力有限)
2. **策划即配置**:战斗的一切数值/时机/规则都在资产里(GE/GA/蒙太奇轨道),不在代码里
3. **最小闭环优先**:先砍出第一剑,再谈华丽

## 1. 核心循环

篝火出发 → 推图清怪(小战) → Boss 战 → 回篝火。线性关卡,一张图走通。

## 2. 移动与输入

| 项 | 决策 | 理由 |
|---|---|---|
| 移动模式 | 自由移动(角色朝移动方向转身,OrientToMovement) | 魂系未锁定状态标准 |
| 锁定模式 | 第 7 章做:面朝敌人 + 八方向平移(2D 混合空间) | 素材里 Jog_Bwd/Left/Right 为此预留 |
| 跳跃 | 有,但弱(探索/跨越用,不是 combat 主力) | 魂系跳跃存在感低 |
| 相机 | 第三人称俯视约 15°、臂长 ~400、开启延迟与碰撞 | 魂系构图:人物偏下 1/3,看得见身前地面 |
| 相机 Y 轴 | 提供反转选项(IMC 里"只翻 Y"的取反) | 玩家偏好分两派,都给 |

## 3. 攻击系统

### 3.1 普攻三连击
- 三段:Attack_PrimaryA → B → C(Greystone 素材)
- 伤害管线:武器胶囊 overlap → 命中事件(带目标)→ GA → GE_Damage → Damage 元属性通道 → 扣血
- **命中判定 = 武器真实扫过空间**(剑刃骨骼 sword_bottom→sword_top 胶囊,跟随动画);判定区间是蒙太奇轨道上可拖的通知状态(ANS_AttackWindow)
- 一刀一名单:同一挥击同一目标只命中一次

### 3.2 连击规则(本项目自定义,非通用)
- 攻击期间**不接新普攻**(同类技能不可重入,引擎天然行为)
- 命中后/后摇中开启**连击窗口**(轨道上可拖的通知 + GE_ComboWindow 授予 State.Combo.Window,0.5s)
- 窗口内输入 → 激活下一段(GA_2/3 的激活所需标签 = State.Combo.Window,窗口外静默失败)
- 窗口后接 → 取消上一段,播下一段

### 3.3 体力
- 每段普攻 -20(GE_Cost 挂在 GA 的 Cost 上)
- 体力 100 起步,消耗节奏 = 连打 5 段空体(待定,后续按手感调)
- 回复:待定(第 5 章做 Duration/Periodic 回复 GE)

## 4. 输入门控(移动锁)

### 设计决策(重要,本项目自选规则)
- 普攻期间**锁定移动与跳跃**,窗口时长 = 轨道上可拖的区间(ANS_MoveLock 区间 → GE_MoveLock → State.MoveLocked)
- **技能可以覆盖普攻**(打断并接管)——不是所有游戏都有这个说法,这是我们的要求
- **技能不一定锁移动**:锁不锁由每个技能自己配不配 GE_MoveLock 决定,与技能强度无关
- 移动锁的解除 = GE 到期自动解除(时长制,不靠命令式开关)

### 层级查询原则
任何系统要查"是否锁移动",读 `State.MoveLocked` 标签;要查"是否在攻击",读 `State.Attacking`。
**规则在 GE/轨道(策划),查询在标签(任何人),执行在通用闸门(代码一次写好不含规则)。**

## 5. 技能哲学

- 本项目**不强制需要"技能系统"**——魂游的战技与普攻同级,不是大招循环
- 若以后加战技:与普攻同级的 GA,不进冷却循环,吃体力/资源即可
- 格挡/弹反(素材有 Deflect_InPlace)优先级高于战技,属第 5 章后扩展项

## 6. 伤害与受击

- 伤害 = GE 写 Damage 元属性 → 结算回调统一处理(扣血/钳制/将来:无敌帧查询、减伤、死亡)
- 受击反应:HitReact 四方向素材(第 5 章)
- 无敌帧(翻滚):第 5 章,State.Invulnerable + AnimNotifyState 窗口(无敌窗是动画数据不是代码)
- 削韧/硬直:扩展项(State.Stunned,Stun_Start/Stun_Idle 素材已有)

## 8. 反面教材(明确不做)

- ❌ "全蓝图"式:效果全堆一个蓝图、轨道不参与、策划慢放对时间轴
- ❌ "全轨道"式:效果全堆轨道、轨道臃肿自由度低
- ✅ 我们:**时机在轨道(可拖)、效果在 GA/GE(资产)、规则在 GE(策划)、执行在通用闸门(代码一次)**
