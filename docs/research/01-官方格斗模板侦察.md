# Variant_Combat 格斗模板技术侦察报告

> 调研对象：`E:/UE5.8Project/格斗游戏模板`（UE 5.8 官方模板副本，纯蓝图，启用 ModelingToolsEditorMode + GameplayStateTree）
> 调研日期：项目启动日。用途：魂类 ARPG demo 技术侦察。

## 1. 是否使用 GAS？—— 否

- 无 `Config/DefaultGameplayTags.ini`。
- 全 Content 扫描 uasset 字符串表：`AbilitySystem` 零命中；`GameplayTag` 仅出现在 `ST_CombatEnemy.uasset`，是 StateTree 自带的状态标签机制，非 GAS。
- 血量/伤害走 UE 内置 `ApplyDamage / AnyDamage (UDamageType)` + 自定义蓝图接口：
  - `Blueprints/BPI_Damageable.uasset` — 受击接口
  - `Blueprints/BPI_Attacker.uasset` — 攻击者接口（Do Attack Trace、Check Combo、Do Melee Attack Damage）
  - 角色内有 `Current HP`、`BaseDamage`、`Knockback` 变量，UI 通过 `Set Life Percentage` 更新血条。

## 2. 战斗系统结构（`Content/Variant_Combat/Blueprints/`）

| 资产 | 作用 |
|---|---|
| `BP_CombatCharacter` | 玩家角色，实现 BPI_Attacker + BPI_Damageable |
| `AI/BP_CombatEnemy` | 敌人角色，受击刷 `NS_Damage` 特效 + `UI_LifeBar` |
| `AI/BP_CombatAIController` | AI 控制器，挂 StateTreeAIComponent → ST_CombatEnemy |
| `AI/BP_Combat_EnemySpawner` | 敌人生成器 |
| `BP_CombatGameMode` / `BP_CombatPlayerController` | 模式与控制器 |
| `BP_CameraShake_Hit_Player/Enemy` | 受击镜头震动 |
| `Interactables/` | 木桩、可破坏箱、检查点 Volume、激活 Volume、岩浆地板 |

**连击组织（AnimNotify 驱动，最值得借鉴）**（`Variant_Combat/Anims/`）：

- `AM_ComboAttack` — 三段连击 Montage，按 Section 组织，`Montage_JumpToSection` 推进
- `AN_AttackCombo` — Notify，在连击窗口调 `BPI_Attacker.Check Combo`：窗口内再次输入则跳下一段
- `AN_AttackDamage` — Notify，调 `BPI_Attacker.Do Attack Trace` → `SphereTraceMultiForObjects` 球体多目标扫掠命中 → ApplyDamage + 击退 + 镜头震动
- `AM_ChargedAttack` / `AN_ChargedAttack` — 蓄力攻击
- `ABP_Manny_Combat` — 战斗动画蓝图

伤害链路：`Montage Notify(AN_AttackDamage)` → `DoAttackTrace` → `SphereTraceMultiForObjects` → `BPI_Damageable` → `ApplyDamage` → 受击方扣 HP。

## 3. AI 结构 —— 纯 StateTree，无 BehaviorTree / 无黑板

- `AI/ST_CombatEnemy.uasset` — 敌人 StateTree。状态：Idle / Moving / Attacking / Evade / Flank / Fallback / Dead。参数：Current HP、Distance to Target、Target Melee Distance、各状态下闪避概率 EvadeProbability*、bAllowStrafe 等。行为："绕玩家走位并贴近近战"，行为后随机等待再决策。
- `AI/StateTreeTasks/`（9 个蓝图 Task/Condition）：ComboAttack、ChargedAttack、FaceActor、FaceLocation、GetPlayerInfo、SetCharacterSpeed、WaitForLanding + Condition：IsCharacterGrounded、IsInDanger。
- EQS（`AI/EQS/`）：EnvQuery_Evade / Flank / Fallback + Context：Player / Danger。
- 无 BehaviorTree、无黑板、无 AIPerception（用 GetPlayerInfo 直接抓玩家）。

## 4. Input（Enhanced Input）

- `Variant_Combat/Input/IMC_Combat` 叠加在基础 `IMC_Default` 上。
- `IA_ComboAttack`(LMB) / `IA_ChargedAttack`(RMB) / `IA_ToggleCameraSide`。
- 基础：`IA_Move`、`IA_Look`、`IA_MouseLook`、`IA_Jump`。
- **无锁定、无翻滚输入**（`MM_Dash` 动画存在但未接线）。

## 5. UI

仅 `UI/UI_LifeBar`（通用 ProgressBar，玩家+敌人头顶 3D 复用）。无 Boss 条、无体力条、无锁定指示。受击特效 `VFX/NS_Damage`（Niagara）。

## 6. Config 注意点（重要风险）

- **该副本的 `DefaultEngine.ini` 已损坏**（262KB 大部分被 `?` 填充，中文路径嫌疑最大）。不要以它为基底开发；只挑资产迁移。我们的工程必须保持纯英文路径。
- `Lvl_Combat.umap` 是 World Partition 地图。

## 7. LevelPrototyping —— 可直接用于灰盒

`SM_Cube/SM_ChamferCube/SM_Cylinder/SM_Ramp/SM_Plane` + 网格材质 `MI_PrototypeGrid_*` + BP_DoorFrame / BP_JumpPad / BP_WobbleTarget。配合 ModelingToolsEditorMode 搭灰盒够用。

## 8. 迁移结论

**可借鉴/迁移（价值从高到低）：**
1. 连击框架：AM_ComboAttack + AN_AttackCombo（连击窗口）+ AN_AttackDamage（命中帧）+ Notify→接口→Trace 链路。改造 GAS 时 Notify 改为发送 GameplayEvent，Trace 逻辑保留。
2. 近战命中模式：SphereTraceMultiForObjects + HitResult 分解 + 按骨骼定位。
3. 敌人 AI 全套：ST_CombatEnemy + 9 个 Task + 3 个 EQS——魂类群战走位，参数化便于调 Boss 变体。
4. 打击感：相机震动、NS_Damage、Knockback。
5. 关卡功能件：CheckpointVolume（→篝火）、LavaFloor、Dummy、EnemySpawner、灰盒全套。
6. UI_LifeBar → 绑到 GAS Health Attribute。

**需要自建（模板没有）：**
1. GAS 全套（AttributeSet/GE/GA/Tag 体系）。
2. 锁定系统（Lock-on）。
3. 翻滚 + 无敌帧。
4. 体力条。
5. Boss 战（血条 UI、阶段机制）。
6. Greystone 接入（用 Paragon 自带骨架与动画，不经 Manny，无需重定向）。
